The app's mark: a film rating box, "RATED" reversed out of an ink bar over a red "ARR", set in Anton.

**Use** the banner on the TV's launcher row and the icon where the launcher wants a square. Inside the app the name is plain text in the `wordmark` style, never the box.

**Look.** `ink` frame and bar, `on-focus` newsprint inside, `focus` red for "ARR". The banner sits on the screen gradient with a halftone screen; the icon is the box alone on transparent.

**In the app:** `drawable-xhdpi/banner.png`, `mipmap-*/ic_launcher.png`, drawn by `tools/make_art.py`.
