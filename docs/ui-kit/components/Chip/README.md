A genre filter under Downloading: For you, So bad it's good, Action and so on.

**Use** for one-of-many filters that swap the rows below. Unlike tabs, a chip changes the page only when pressed, so scrolling past them is free.

**Provide** the genre name in `label` type. "For you" always comes first.

**States.** As Tab: chosen is `glass-selected` with a `line` outline, focused is the `focus` fill. Padding `space-4`, height `control-s`.

**In the app:** `@style/Chip`, `@layout/chip`, `@layout/genre_chips`.
