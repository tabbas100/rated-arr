Two sets of round marks for episodes: what you have, and what you picked.

**Have:** downloaded (a `ready` disc with a tick), partly (a `warning` ring, half filled), missing (a `danger` disc with a cross). Shown only for shows in your library, and only for episodes that have aired.

**Pick:** picked (an `accent` disc with a tick), some picked (an `accent` disc with a dash), not picked (an `ink-dim` ring).

**Rules.** Never use colour alone: each mark has its own shape (tick, half, cross, dash, ring). Have marks are 18px, pick marks 22px.

**In the app:** `drawable/ic_have_all`, `ic_have_some`, `ic_have_none`, `ic_pick_all`, `ic_pick_some`, `ic_pick_none`.
