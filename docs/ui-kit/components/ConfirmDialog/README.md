The question before anything is deleted.

**Use** for every delete: a film's file, a whole title, some episodes.

**Provide** a title that names the thing ("Delete the file of “Watchmen”?") in `title` type, and a body in `body` type that says how much space it frees and that it can't be undone.

**Rules.** Cancel has the focus when the dialog opens, so pressing OK by habit deletes nothing. The destructive button says what it does ("Delete", "Remove") in `danger`.

**Look.** `surface-raised`, `radius-l`, padding `space-6`, `lift`.

**In the app:** `Confirm.ask`.
