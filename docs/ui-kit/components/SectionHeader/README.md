The title above a row of cards, with an optional note.

**Use** above every row: "Downloading", "Films with Steven Seagal", "So bad it's good".

**Provide** the title in `heading` type, set in capitals, `ink-dim`. A note goes underneath in `card-meta` and `warning` only when the row needs attention ("Plex can't play disc images…").

**Spacing.** Rows are `row-gap` apart; the title sits `gutter` from the left edge.

**In the app:** `@layout/section_row`, `Text.Section`.
