One title that is downloading: a film, or all of a show's episodes together.

**Use** in the Downloading row at the top of home. Opening it lists each episode.

**Provide** a thumbnail, the title, a detail line (quality, or the episode count), the average progress and one status line.

**Status.** Normal: "64% · 12 min left" in `ink-dim`. Needs attention (stalled, missing files, import blocked): Radarr's or Sonarr's own words in `warning`.

**States.** Focused: `glass-selected`, `focus` ring, scale `focus-scale-wide`. Width `download-w`, `radius-l`, padding `space-4`.

**In the app:** `@layout/card_download`, `Cards.downloadGroup`, `drawable/card_bg`, `drawable/progress_bar`.
