The app's vector drawables as SVG, on a 24-unit grid with the app's current colours. In the UI the marks take the tokens noted here.

- `have-all.svg`: downloaded, a disc in `ready` with a tick in `on-ready`.
- `have-some.svg`: partly downloaded, a ring half filled in `warning`.
- `have-none.svg`: missing, a disc in `danger` with a white cross.
- `pick-all.svg`, `pick-some.svg`: picked or partly picked, a disc in `accent` with a tick or dash in `on-accent`.
- `pick-none.svg`: not picked, a white ring at 60%.
- `check.svg`: the tick inside the Ready / In library badge, in `on-ready`.
- `search.svg`: the magnifier in the search field, white; takes `ink-faint` at rest.
